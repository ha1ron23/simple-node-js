# simple-node-js

A clean and simple starter template for Node.js projects with ES Modules support.

## 🚀 Features
- **ES Modules** enabled (`import/export` out of the box).
- **Auto-reload** on file changes using native `node --watch`.
- Production-ready directory structure (`src/`).

## 🛠️ Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ha1ron23/simple-node-js.git
   cd simple-node-js
   ```

2. **Run the script once:**
   ```bash
   npm start
   ```

3. **Run in development mode (with auto-reload):**
   ```bash
   npm run dev
   ```
